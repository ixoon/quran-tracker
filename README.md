# Quran Tracker

Project scaffold only — app features are not implemented yet.

## What's included

- Expo (React Native) + TypeScript + Expo Router (tabs template)
- NativeWind / Tailwind configured (`babel.config.js`, `metro.config.js`, `tailwind.config.js`)
- Planned stack dependencies installed (Supabase, Zustand, Adhan, etc.)
- Documentation in `docs/`
- Supabase SQL in `supabase/schema.sql`

## Docs

- [PRD](docs/PRD.md)
- [Tech](docs/Tech.md)
- [DB](docs/DB.md)

## Run

```bash
npm install
npx expo start
```

## Environment (when you connect Supabase)

Copy `.env.example` → `.env` and add your keys.
